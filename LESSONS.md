# Lessons

- Partial clones append `[<filter>]` to `git remote -v` fetch lines. Repository identity parsing must allow that suffix; a missing identity splits repository groups and prevents automatic scheduling across those project copies. Reproduce with real Git promisor/filter configuration.
- Fork CLI archives built on GX10 need `VP_NODE_VERSION=26.8.2` for `build-exe` (vite-plus defaults to Node 24, which rejects tsdown's exe option) and `scripts/update-release-package-versions.ts <version>` first, or the smoke test fails with `t3 v0.0.45`.
- The Browser panel runs on the client, not the server host: a worktree dev server is only reachable through a LAN address, which needs `T3CODE_DEV_ALLOWED_HOSTS=<ip>` and a forwarder to Vite's loopback port.
- Electron extension service workers stop after ~30 s idle and restart on the next message, sometimes reusing the same `ServiceWorkerMain` (and its `ipc`) and sometimes not. Register `serviceWorker.ipc.handle` once per worker object, never per "running" transition: a second `handle` throws inside the `running-status-changed` event, and Electron's default uncaught-exception dialog then blocks the main process (DevTools stops answering).
- Electron prints nothing for main-process uncaught exceptions it shows in its default dialog. To see them on a test run, attach to `--inspect` and add a `process.on("uncaughtExceptionMonitor")` recorder, which does not change the default behavior.
- Mac test runs need a short `TMPDIR` (`mktemp -d /var/tmp/t3emb-XXXXXX`): the desktop app's control socket under a long sandbox path exceeds the 104-byte Unix socket limit and fails with `listen EINVAL`.
- Managed native pages must mount from the global preview event stream, including Settings/remote opens, before the engine waits for the per-tab desktop relay. Mounting only the active chat deadlocks first open. Shared participants use the engine page identity for a single guest and a managed-only persistent partition.
- A native preview slot inside a dialog needs both a flex parent with height and a surface layer above the dialog. An outer renderer screenshot can include the guest; zero-height slots produce blank content. OS screen capture over SSH still requires separate Mac permission, so renderer evidence does not prove physical input or OS capture.
- Patchright evaluation uses an isolated world. Main-world evasions require the scoped Electron debugger's new-document registration plus immediate evaluation, an origin guard, a document marker, and one desktop-owned registration across engine reconnects.

- Normal Browser panel opens use `previewOpen`, not the Settings managed-browser controls. An owner-native guest must be created only from the authenticated owner snapshot; a remote chat shadow can reference that guest but must never choose its local partition or relay authority. Validate the normal chat entry point before declaring managed browser integration complete.
- Agent cursor overlays must share the page slot's containing block. Placing one outside the managed control bar offsets every pointer by the bar's height (44 px in the Mac staging check). Verify an actual peer hover/click against the webview's rectangle, not just the pointer event coordinates.
